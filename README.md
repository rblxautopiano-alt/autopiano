## 📖 Detailed Overview

**Roblox Auto Piano** is a high-speed sheet music auto-player designed for Roblox piano games. 

Instead of requiring users to install Python, configure command lines, or install external libraries, this application is pre-compiled into a **standalone Windows `.exe` executable**.

### 🧠 How the Smart Search Engine Works

Finding piano sheets manually across different sites takes time. This tool features a custom **Smart Search Engine** connected to a massive, manually curated index database containing over **3,000 to 4,000+ cataloged songs**.

- **GitHub Cloud Database:** The search engine pulls directly from a giant online index text file.
- **Deep Metadata & Tag Searching:** You can search not just by exact song titles, but by **lyrics, key fragments, artist names, or custom tags**.
- **Multi-Source Fetching:** Once a match is selected from the index, the app fetches and parses the actual sheet notation directly from **3 major sources**:
  1. 🎹 **VirtualPiano**
  2. 🎼 **VPSheets**
  3. 🎶 **PlayPianoSheets**

## 🛡️ Executable Security Notice

### Why is this file an `.exe`?
This tool is written in Python and compiled using `PyInstaller` / `Nuitka` into an `.exe` wrapper. This bundles the required dependencies (such as GUI libraries, HTTP requests, and virtual keyboard controllers) into a single file so anyone on Windows can run it out-of-the-box.

> ⚠️ **Antivirus Warnings (False Positives):**  
> Unsigned compiled Python scripts that emulate keyboard events (to press keys in Roblox) are sometimes flagged as false positives by Windows Defender or SmartScreen. The source code is publicly accessible right here in this GitHub repository for full transparency.
